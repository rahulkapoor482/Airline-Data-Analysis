# Airline Data Analysis | PostgreSQL & Power BI

## Overview
A data analytics project focused on analyzing airline passenger, flight, route, and seat capacity data using PostgreSQL and Power BI.

## Key Analysis
* Analyzed passenger and flight trends over time
* Identified busiest airports and top routes
* Calculated passengers per flight and load factor
* Compared seat capacity with passenger demand
* Analyzed route and utilization performance
* Created SQL queries using CTEs, aggregations, and window functions

## Dashboard
 **2-page Power BI dashboard** covering:
* Passenger & flight overview
* Passenger trends
* Top airports and routes
* Capacity vs passenger demand
* Flight utilization
